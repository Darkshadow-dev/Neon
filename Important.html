Arduino Error Guide

This page explains the most common Arduino IDE and Arduino CLI errors. Click any button below to jump directly to an error, see an example, learn why it happens, and discover the quickest way to fix it. Whether you're using an official Arduino board or a clone, these solutions cover the problems beginners and experienced users encounter most often.

Arduino CLI Upload Error

Error: Programmer is not responding.
This usually happens because of wrong upload speed, wrong COM port, missing driver, or a clone Arduino board using a different bootloader. 
arduino-cli upload -p COM5 --fqbn arduino:avr:uno blink

Error: programmer is not responding
Warning: attempt 1 of 10: not in sync: resp=0x00

Error: unable to open port COM5 for programmer arduino

Failed uploading: upload error: exit status 1

Try this fix:

arduino-cli upload -p COM5 --fqbn arduino:avr:uno --upload-property upload.speed=57600 blink
Why this works:
Many cheap Arduino UNO clones use a slower bootloader speed. The normal UNO uses 115200, but some CH340/clone boards work better with 57600.

Access is Denied

Error: Windows is preventing Arduino CLI from using the serial port. 
Error:
unable to read:
Access is denied.
Usually caused by
  • Serial Monitor still open
  • Arduino IDE using the port
  • Another terminal program
  • USB disconnected while uploading

Unable to Open Port

Error: Arduino CLI could not connect to the selected COM port. 
Error:
unable to open port COM5
Check
  • Correct COM port
  • USB cable connected
  • Driver installed
  • Board powered

Missing FQBN

Error: Arduino CLI does not know which board you are compiling for. 
Error:
Missing FQBN
Always add --fqbn arduino:avr:uno or the correct board name.

Error: The compiler expected a semicolon before continuing. 
expected ';'

before
Check the line above the error. A missing semicolon often causes the compiler to report the error on the next line.
