Talking About The Guide

This guide started as a simple project in Notepad and slowly became a full Arduino learning website.

Why I Made This:
I wanted a guide that explains Arduino in a simpler way without forcing users to read huge documentation pages.


Learning Style

I prefer visual tutorials and interactive examples.

  • I personally think that showing how something works and why together is much better
  • Than showing just how or why something works

The focus of the guide is to help you so you can leave it behind.

If a Guide or a Website taught you so much that you forget or need to go back to it all the time.

  • Then you learned nothing
  • Guide/Website is using your time to earn money
  • You'll barely get anything out of it

I wanted and I think I made a guide that teaches you and doesn't need you to come back almost at all

Why Notepad?

I wanted everything understandable and editable.

I learned how to use Notepad and I like to make my stuff only revolve around itself without any external help

And for that reason the whole guide uses only 4 libraries and one Python server and one downloadable Python script

Really it's my own stubbornness that made me make this guide how I did.

How I feel about it?

Great, never better, but a bit sad as I ran out of ideas and also am about to finish it after so long.

To answer one question that I got asked a few times:

What if nobody uses your website, would you be sad?

I feel not everything needs to be seen and used, especially if we go to talk about art.

I personally have a sketch book where I made many great and many bad drawings, but nobody will see any of them.

But I still made them, why? Because I learned something new or made old things better.

Same as with this guide website, the first 3 were as bad as possible, yet they are mine, but this one in this much time got this far.

I learned multi-page, 3D render, gallery, stylesheet, and so much more that I can use and reuse for future projects.

I'm happy knowing I did it.

Now if someone would use it I would be as happy as possible, and if somehow some people would use it at times I would, idk, be over the moon.

I'm just happy that I did it. If nobody sees it, idc.
