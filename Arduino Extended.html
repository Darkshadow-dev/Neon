Known Limitation

Multiline arithmetic continuation is currently not supported in the same way as normal Arduino C++ source.

This form works:

targetTime = 1000 + map(pot, 0, 1023, 500, 4000);

While splitting the same expression across multiple lines can currently produce an unsupported GSE instruction.

This is a simulator parser limitation, not a limitation of the Arduino Uno itself.
