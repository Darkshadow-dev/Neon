About the Arduino Board - Showcase

The Arduino Uno is a beginner-friendly microcontroller board designed to interact with the physical world. It can read sensors, control outputs, and run a program continuously without an operating system.

At its core is the ATmega328P microcontroller. Unlike a PC CPU, this chip runs a single sketch in a loop and directly controls hardware pins.

Think of Arduino as a tiny computer built only to control electronics. No apps, no windows — just code and signals.

Arduino Board – Hardware & Components - Diagram Documentation

This section explains the physical parts of an Arduino board and how real components connect to it. All diagrams are simple, clear, and approachable, matching real wiring.

Microcontroller (The Brain)

The microcontroller is the main chip on the Arduino. On the Arduino Uno, it is the ATmega328P.

  • Executes your program line by line
  • Runs the loop() function continuously
  • Reads inputs from pins
  • Controls outputs like LEDs and motors

Click on each section to learn more about important Arduino hardware components.

Power System

The Arduino can be powered in multiple ways:

  • USB – 5V from computer
  • VIN – 7–12V external supply (raw input voltage, regulated onboard)
  • 5V pin – regulated output (limited current)
  • GND – ground (must always be connected)

Important: Never power motors directly from Arduino 5V.

Why: Motors draw high current and can create electrical noise — use a driver and a diode.

Rule: Arduino controls signals, not power.

Digital Pins (0–13)

Digital pins can be either ON (HIGH) or OFF (LOW). See the LED example on the Examples page.

  • Used for buttons, LEDs, relays
  • Pins with ~ support PWM
  • Pin 13 has a built-in LED
Analog Pins (A0–A5)

Analog pins read voltage levels, not just ON/OFF.

  • Range: 0–5V
  • Values: 0–1023 (10-bit resolution)
  • A4 = SDA, A5 = SCL (I²C)
Resistors

Resistors limit current and protect components.

  • Used with LEDs
  • Typical values: 220Ω, 330Ω, 1kΩ, 10kΩ
  • Direction does NOT matter
  • Can be placed on either side of an LED
Capacitors

Capacitors smooth voltage and reduce noise.

  • Ceramic: no polarity
  • Electrolytic: Capacitors are polarized; + and − terminals matter
  • Electrolytic: Connecting electrolytic capacitors incorrectly can damage them.
  • Used near motors and power
Motors (DC & Servo)

Motors draw high current and must NOT be connected directly to pins.

  • Use motor driver or transistor
  • External battery required
  • Common GND with Arduino
  • Use flyback diode for DC motors
Sensors

Sensors convert physical values into electrical signals.

  • Distance sensors
  • Temperature sensors
  • Light sensors

Arduino Uno Basics

The Arduino Uno uses an ATmega328P microcontroller. The pins around the board allow it to communicate with LEDs, buttons, sensors, displays, motors, and other electronics.

Core Parts
  • ATmega328P — the main microcontroller.
  • USB port — connects the Arduino to a computer and can provide power.
  • DC barrel jack — external power input.
  • Voltage regulator — helps regulate incoming power.
  • Digital pins — pins 0–13 for digital input/output.
  • Analog pins — pins A0–A5 for reading analog signals.
  • Power pins — 5V, 3.3V, VIN and GND.
  • Reset button — restarts the running program.
  • Pin headers — provide connections for components and expansion.
Digital Pins — 0 to 13

Digital pins can normally be used as INPUT or OUTPUT. They can read a signal or control a component.

For example, an LED can be controlled from pin 13, while a button can be connected to another digital pin.

Pin 0 (RX) and Pin 1 (TX) are also used for serial communication. Be careful when using them while uploading or communicating with the computer.

Pin 11? It is a normal digital pin and also supports PWM and SPI functions.

Pin 12? Digital pin with SPI support.

Pin 13? Digital pin connected to the Uno's built-in LED.

PWM Pins

Pins marked with ~ support PWM. On the Arduino Uno these are:

3, 5, 6, 9, 10 and 11

PWM can be used for things such as controlling LED brightness or controlling the speed of some motors.

Analog Pins

A0–A5 can read changing voltages from analog sensors and other components.

A common example is a potentiometer or analog sensor connected between power, GND and one analog input.

I²C — A4 and A5

On the Arduino Uno:

  • A4 = SDA
  • A5 = SCL

These pins are commonly used by I²C displays, sensors and other I²C devices.

SPI Pins

The main SPI pins on the Uno are:

  • 10 = SS
  • 11 = MOSI
  • 12 = MISO
  • 13 = SCK

SPI is commonly used by displays, SD cards, sensors and other high-speed peripherals.

Power Pins
  • 5V — regulated 5V supply.
  • 3.3V — regulated 3.3V supply.
  • GND — ground / negative reference.
  • VIN — voltage supplied to the board's external power input.

Always check the voltage requirements of the component you are connecting. Not every module is designed for 5V.

What Is GND?

GND means ground. It provides the electrical reference and return path for a circuit.

When connecting a normal LED, sensor, button, display or buzzer, the circuit will commonly need a connection back to Arduino GND.

Multiple components can share Arduino GND when the wiring and power requirements are appropriate.

LED + and −

A typical LED has two legs:

  • Longer leg — usually positive / anode (+).
  • Shorter leg — usually negative / cathode (−).

The negative side is commonly connected toward GND. The positive side should normally be connected through a current-limiting resistor.

A resistor is important because connecting an LED directly to a power source can allow too much current to flow.

Resistors

Resistors limit current and control electrical signals.

For basic LEDs, a resistor such as 220Ω is commonly used, although the correct value depends on the LED and circuit.

Buttons

A button is commonly used as a digital input. The Arduino reads whether the input is HIGH or LOW.

A button circuit normally needs a defined pull-up or pull-down state so the input does not randomly change when the button is not pressed.

Arduino's internal INPUT_PULLUP can often simplify basic button circuits.

Buzzer

A buzzer can be connected to a digital or PWM-capable pin depending on the type of buzzer and how it is being controlled.

A passive buzzer can be driven with changing frequencies, while an active buzzer normally produces its own tone when powered.

Larger buzzers, speakers and motors may require a transistor, driver or separate power source instead of being driven directly from an Arduino pin.

Sensors — Quick Rule

Sensors can communicate with Arduino in different ways.

  • Analog — usually read with A0–A5.
  • Digital — usually read with a digital pin.
  • I²C — commonly uses SDA and SCL.
  • SPI — uses the SPI communication pins.
  • Serial — communicates through serial TX/RX.

Always check the module's pin labels and voltage requirements before connecting it.

Breadboards

A breadboard lets you build circuits without permanently soldering the components together.

The holes are electrically connected in groups underneath the board. Power rails are commonly used to distribute 5V and GND around the circuit.

Quick Pin Reference
  • 0 — RX / Serial
  • 1 — TX / Serial
  • 3 — PWM
  • 5 — PWM
  • 6 — PWM
  • 9 — PWM
  • 10 — PWM / SPI SS
  • 11 — PWM / SPI MOSI
  • 12 — SPI MISO
  • 13 — SPI SCK / Built-in LED
  • A0–A5 — Analog input
  • A4 — I²C SDA
  • A5 — I²C SCL
  • 5V — 5V power
  • 3.3V — 3.3V power
  • GND — Ground
  • VIN — External power input
Before You Connect Something
  • Check the component's required voltage.
  • Check which pin is power and which is GND.
  • Use a resistor where the circuit requires one.
  • Do not short 5V directly to GND.
  • Do not assume a motor or speaker can be powered directly from an Arduino pin.
  • Check the wiring before powering the circuit.

Remember: this section is a reference, not a path you have to complete. If you only came here because you forgot what pin 11 does, find pin 11 and get back to your project.

Arduino Explained - Text Documentation

Arduino is an open-source electronics platform based on easy-to-use hardware and software. It is used to read sensors, control motors, displays, lights, and communicate with other devices.

🧠 What is Arduino?

An Arduino board is a small computer called a microcontroller. Unlike a PC or laptop, it does not run an operating system. Instead, it runs one program over and over again and directly controls electronic components connected to it.

Arduino is designed to interact with the real world. It can sense its environment, make decisions, and react instantly without needing a keyboard, mouse, or screen.

  • Reads inputs – buttons, sensors, joysticks, distance sensors
  • Processes logic – your code decides what should happen
  • Controls outputs – LEDs, motors, buzzers, relays, displays

This makes Arduino ideal for learning electronics, building projects, automating tasks, and creating interactive devices.

🧩 Main Components on the Board:
  • Microcontroller (ATmega328P) – the brain
  • USB Port – programming and power
  • Voltage Regulator – keeps voltage safe
  • Crystal Oscillator – timing (16 MHz)
  • Capacitors – smooth power (+ / − matters)
  • Resistors – limit current
📍 Pin Layout

Arduino Uno pins are grouped by function:

Digital Pins (0–13):

  • Read HIGH / LOW
  • Some support PWM (~)
  • Pin 0 & 1 are used for USB serial
  • Note: Digital pins can safely supply ~20mA each (40mA absolute max), and total current from all I/O pins should not exceed ~200mA.

Analog Pins (A0–A5):

  • Read voltage (0–5V by default)
  • Resolution: 10-bit (0–1023)
  • AREF can change reference voltage
  • Mapped to values 0–1023
  • A4 = SDA, A5 = SCL (I²C)

Power Pins:

  • 5V – regulated output (limited current, do NOT power motors)
  • 3.3V – low power devices
  • GND – ground
  • VIN – external power input
D0–D13 → Digital
A0–A5 → Analog
5V, 3.3V, GND → Power
🔌 Communication Methods
  • UART (Serial) – Pins 0 (RX) & 1 (TX)
    Used for uploading code, debugging, and communicating with PCs or Bluetooth modules.
  • I²C – SDA & SCL (2 wires, shared bus)
    Connect many devices like OLEDs, sensors, RTCs using addresses.
  • SPI – SS, MOSI, MISO, SCK
    Pins on Uno:
    • SS → D10
    • MOSI → D11
    • MISO → D12
    • SCK → D13

Tip: I²C is easiest for beginners; SPI is fastest.

💾 Memory Inside Arduino
  • Flash (32 KB) – stores your program
    Code stays even when power is off.
  • SRAM (2 KB) – working memory
    Variables, arrays, and calculations while running.
  • EEPROM (1 KB) – long-term storage
    Save settings, scores, or calibration data.

Warning: Running out of SRAM causes crashes.

⚡ Powering Arduino
  • USB (5V) – easiest and safest for beginners
  • VIN – external power input (recommended 7–12V)
  • 5V Pin – direct regulated power (advanced users)

Never exceed voltage limits.
Motors and high-power devices need separate power.

💻 Software & Downloads
  • Arduino IDE – official graphical programming tool
    Easy to use, recommended for beginners.
  • Arduino CLI – command line interface (CMD / Terminal)
    Advanced, scriptable, fast, and very powerful.
  • Works on Windows, Linux, macOS
  • Uses a C / C++ style language compiled before upload
  • Libraries add support for displays, sensors, motors, storage
  • Commands: 
    arduino-cli.exe compile --fqbn arduino:avr:uno blink
arduino-cli.exe upload -p COM8 --fqbn arduino:avr:uno blink

Why Arduino CLI / CMD is rarely mentioned:

  • Arduino focuses on beginners and education
  • CLI requires understanding paths, boards, and toolchains
  • No visual editor or built-in serial monitor by default
  • Can be confusing without prior programming experience

However: Using Arduino from CMD is not wrong. It is actually more professional and commonly used in:

  • Automation and scripting
  • Build systems and CI pipelines
  • Minimal systems (no GUI)
  • Advanced or custom workflows

Code is compiled and uploaded via USB, then runs automatically when powered.

Tip: The Arduino IDE internally uses the same tools as Arduino CLI.

  • Short-circuiting pins with wires
