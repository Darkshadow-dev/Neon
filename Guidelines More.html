CMD Guide

MS-DOS Guide
Description about the Guide

This guide is a complete beginner-friendly way to learn MS-DOS through simple explanations, visual examples, and interactive pages.

Instead of only showing commands, the guide explains what they do, why they exist, and how they work together inside the system.

The built-in simulator lets you safely test commands directly in the browser, making it easier to learn through experimentation and practice.

The guide focuses on keeping everything understandable, lightweight, and easy to follow without requiring advanced tools or complicated setups.

It is designed to help people actually understand MS-DOS rather than memorize commands without context.

MS-DOS Guide Sanke Game
Description about the Sanke Game

This page recreates the classic MS-DOS Snake game directly inside the browser while keeping the retro terminal-style feeling of the original versions.

The game is made to be simple, lightweight, and easy to understand, matching the style and philosophy of the main MS-DOS Guide.

It helps show how old DOS-style games looked and behaved while also giving users something interactive and fun to experiment with.

The project focuses on recreating the feel of classic keyboard-controlled DOS games using modern web technologies without losing the old-school atmosphere.
